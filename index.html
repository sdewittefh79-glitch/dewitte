Tools Used for Building

For the Delegation sample, Vyond was used to create the character animation and Audacity was used to create and edit the audio for the character introduction. The remainder of the Delegating sample was built from scratch using client-side code. I used HTML for structure and responsiveness, CSS for styling and roll-over effects, and Javascript event listeners for video interaction and page navigation. A full descripton of the build for the Leadership Development Wheelspin Game is included within the demo.
